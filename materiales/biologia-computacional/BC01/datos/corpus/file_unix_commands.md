# Comandos UNIX esenciales para bioinformática

## Navegación
- `pwd`: imprime directorio actual
- `cd`: cambia de directorio
- `ls -la`: lista con detalles

## Visualización
- `cat`: muestra contenido
- `head`: primeras líneas
- `tail`: últimas líneas
- `less`: visualización paginada

## Búsqueda y filtrado
- `grep`: busca patrones
- `find`: busca archivos
- `wc`: cuenta líneas, palabras, bytes

## Gestión de archivos
- `cp`, `mv`, `rm`: copia, mueve, elimina
- `mkdir`: crea directorio
- `tar`: comprime/descomprime
