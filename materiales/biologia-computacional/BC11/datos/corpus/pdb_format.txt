# Formato PDB (Protein Data Bank)
# Registros principales:
#   HEADER   - Título del estudio
#   COMPND   - Nombre de la proteína/complexo
#   HETATM   - Atomo no estandar (ligandos, metales, agua)
#   ATOM     - Atomos estandar de la proteina
#   TER      - Fin de cadena polipeptidica
#   END      - Fin del archivo

# Columnas en ATOM/HETATM:
# 1-6  Record type (ATOM  o HETATM)
# 7-11 Atom serial number
# 13-16 Atom name
# 17   Alternative location indicator
# 18-20 Residue name
# 22   Chain ID
# 23-26 Residue sequential number
# 31-38 X coordinate (A)
# 39-46 Y coordinate (A)
# 47-54 Z coordinate (A))
# 55-60 Occupancy
# 61-66 Temperature factor (B-factor)
