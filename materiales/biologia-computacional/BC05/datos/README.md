# Datos docentes de BC-CH05

El fichero de esta carpeta es sintético, de elaboración propia de Álvaro Serrano
Navarro, y se redistribuye con licencia CC0-1.0. Es el mismo conjunto de
coordenadas que usa el capítulo de estructuras experimentales, para que el
alumnado pueda comparar lo que cada uno calcula sobre la misma molécula.

| Fichero | Contenido | Para qué |
|---|---|---|
| `bc05_estructura.pdb` | trece átomos de tres residuos, más una molécula de agua | calcular distancias, centroide y mapa de contactos sobre coordenadas reales de un fichero |

Para comprobar que no ha modificado nada, desde esta carpeta:

```bash
sha256sum -c manifest.sha256
```
