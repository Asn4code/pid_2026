# Datos sintéticos de TC-CH07

- versión: 1.0.0 (2026-08-06)
- autoría: obra original del proyecto de innovación docente
- licencia: CC0 1.0; pueden copiarse, modificarse y redistribuirse
- procedencia biológica: ninguna; son secuencias didácticas sintéticas
- alfabeto esperado: A, C, G y T en mayúsculas

`tc07_sequences.fasta` contiene cinco controles en orden deliberado. Los dos
archivos restantes provocan, respectivamente, un error de alfabeto y un registro
sin secuencia. `manifest.sha256` permite detectar cualquier cambio en estos tres
archivos y en este documento. Ningún archivo requiere red ni contiene datos
personales o clínicos.
