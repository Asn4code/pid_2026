## Recorrido de la asignatura

| Semana | Módulos y foco | Sesiones |
|---:|---|:---:|
| 1 | **BC01.** Introducción, entorno y reproducibilidad | S01 |
| 1 | **BC02.** Bioquímica esencial como modelo computable | S02 |
| 2 | **BC03.** Genética, genómica y variantes | S03-S04 |
| 3 | **BC04.** Expresión génica y lectura de marcos | S05 |
| 3 | **BC05.** Secuencia, estructura y función de proteínas | S06 |
| 4 | **BC06.** Tecnologías de secuenciación y librerías | S07 |
| 4 | **BC07.** Lecturas, calidad y referencia | S08 |
| 5-6 | **BC08.** Alineamiento y mapeo de NGS | S09-S11 |
| 6-7 | **BC09.** Alineamiento múltiple, curado y filogenia | S12-S14 |
| 8 | **BC10.** Regulación procariota, clonación y plásmidos | S15-S16 |
| 9 | **BC11.** Representación estructural y PDB | S17 |
| 9-10 | **BC12.** Predicción estructural clásica | S18-S19 |
| 10-11 | **BC13.** Predicción estructural con IA | S20-S21 |
| 11-12 | **BC14.** Cribado virtual y priorización de candidatos | S22-S24 |
