# TC08 · Clasificación probabilística, Markov y HMM

Este módulo introduce los modelos ocultos de Markov (HMM) como herramienta de
predicción. Se trabajan matrices de transición, secuencias de emisiones y la
aplicación del algoritmo de Viterbi para identificar regiones codificantes en
secuencias de ADN.

!!! info "Material en preparación docente"
    El capítulo, la práctica individual y los recursos ejecutables se publicarán
    aquí cuando hayan superado la revisión docente. El Campus Virtual indicará
    la versión que corresponde utilizar en la sesión.

## Resultado previsto

Al finalizar el módulo, cada estudiante podrá interpretar los resultados de un
modelo oculto de Markov y usar el algoritmo de Viterbi para predecir estados en
secuencias biológicas.
