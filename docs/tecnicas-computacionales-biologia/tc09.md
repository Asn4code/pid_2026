# TC09 · Alineamiento dinámico y BLAST

Este módulo presenta el alineamiento dinámico como método de comparación entre
secuencias biológicas. Se trabaja con matrices de puntuación, relleno de
tablas de alineamiento local (Smith-Waterman) y se compara con los resultados
producidos por BLAST.

!!! info "Material en preparación docente"
    El capítulo, la práctica individual y los recursos ejecutables se publicarán
    aquí cuando hayan superado la revisión docente. El Campus Virtual indicará
    la versión que corresponde utilizar en la sesión.

## Resultado previsto

Al finalizar el módulo, cada estudiante podrá realizar y validar un alineamiento
dinámico local, interpretar la tabla de puntuación y relacionar el resultado con
una herramienta de búsqueda de homología como BLAST.
