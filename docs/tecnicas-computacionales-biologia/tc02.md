# TC02 · Bash avanzado: bucles, sed y awk

Este módulo profundiza en el uso del shell de Linux para transformar y analizar
datos biológicos. Se trabaja con `sed` para modificaciones de texto en secuencia
y `awk` para el procesamiento de campos y la generación de informes resumidos.

!!! info "Material en preparación docente"
    El capítulo, la práctica individual y los recursos ejecutables se publicarán
    aquí cuando hayan superado la revisión docente. El Campus Virtual indicará
    la versión que corresponde utilizar en la sesión.

## Resultado previsto

Al finalizar el módulo, cada estudiante podrá aplicar transformación de texto y
cálculo de estadísticas básicas sobre conjuntos de datos biológicos mediante
comandos de shell avanzados.
