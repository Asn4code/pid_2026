# TC01 · Linux, Shell, expresiones regulares y formatos

Este módulo introduce el trabajo con la terminal de Linux para el procesamiento
reproducible de datos biológicos. Se crean scripts Bash que automatizan la
exploración de directorios, la filtración con expresiones regulares y la
generación de inventarios y resúmenes.

!!! info "Material en preparación docente"
    El capítulo, la práctica individual y los recursos ejecutables se publicarán
    aquí cuando hayan superado la revisión docente. El Campus Virtual indicará
    la versión que corresponde utilizar en la sesión.

## Resultado previsto

Al finalizar el módulo, cada estudiante podrá escribir scripts Bash simples para
procesar archivos de datos biológicos, verificar su integridad y producir
inventario reproducible de los resultados.

## Evidencia individual

La actividad y su entrega serán individuales. El repositorio contendrá las
instrucciones y los recursos comunes; la evidencia se entregará exclusivamente
en el Campus Virtual.
